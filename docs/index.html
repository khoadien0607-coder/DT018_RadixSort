DT018 — Radix Sort cho mảng có số âm & số dương

✓ 14/14 Tests PASS C99 / C11 O(n) Time & Space
💡 Nguyên lý thuật toán
Mấu chốt: Với hai số âm x, y < 0:   x < y  ⟺  |x| > |y|
→ Sắp độ lớn tuyệt đối tăng dần, rồi đảo chiều, rồi đổi dấu → phần âm đúng thứ tự tăng dần.

📥 Bước 1 — Tách nhóm

Duyệt mảng: phần tử âm → am[] (lưu giá trị gốc), phần tử ≥ 0 → khong_am[]

⚙️ Bước 2 — Sắp xếp Radix LSD

Dùng radix_khong_am() sắp cả hai nhóm theo độ lớn tuyệt đối (cơ số 10, d ≤ 6)

🔄 Bước 3 — Đảo chiều nhóm âm

Độ lớn âm sau Radix tăng dần → đảo ngược → độ lớn âm giảm dần → đổi dấu → âm tăng dần ✓

🔗 Bước 4 — Ghép kết quả

Nối am[] (đã đúng) trước khong_am[] (đã đúng) → mảng hoàn chỉnh tăng dần
